# voxtn-template-general

Vox Agents general-purpose template.

**Primary use case:** default for customers without a specific industry template.
Lands them on a clean Vox Agents config with no industry-specific knobs preset.

**Capabilities (planned):**
- Standard agent personality + behavioral baseline
- Standard skill set (web, terminal, vault, email)
- Customer customizes via their own `SOUL.md` edits

**Status:** v0 scaffold (Phase 1a 2026-05-20). Content (`SOUL.md`, `skills/`, `config.yaml`) added in Phase 1d.
